# Tage Portfolio

Personal portfolio website for Itztagethedev.

## Files
- `index.html` — page content
- `style.css` — responsive design

## Hosting
Enable GitHub Pages in the repository settings and select the `main` branch with the `/ (root)` folder. The site will then be available at:

https://itztagethedev.github.io/tageporfolio/

Static HTML, CSS and JavaScript. No build step or paid hosting required.
